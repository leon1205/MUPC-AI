# 📋 项目环境概览

## 1. 项目定位

**MUPC 微电网特种调控装置通信管理模块**是"异构双核心模块主控架构"中的**非实时处理核心**（大脑），与"实时控制核心模块"（小脑）协同工作。

## 2. 核心架构

### 双核心协同架构
```
通信网关（北向/南向）
       ↓
数据处理与边缘计算 ←→ AI优化引擎 ←→ 本地策略引擎（兜底）
       ↓
核间通信 → 实时控制模块
```

### 关键组件
1. **通信网关** - IEC 60870-5-104、IEC 61850-7-420、MQTT over TLS（北向）；RS485、HPLC、以太网（南向）
2. **数据处理引擎** - 高频遥测（≥1Hz）、故障录波、数据上送
3. **本地策略引擎** - 固定策略/反应式策略，AI失效时的兜底机制
4. **AI边缘优化引擎** - LSTM/TCN预测、MADDPG/PPO强化学习
5. **核间通信** - 共享内存与实时控制模块交互

### 协议与安全
- **协议**：IEC 104（调度）、IEC 61850（配电）、MQTT（物联/VPP）
- **安全**：国密SM2/SM4、双向证书认证、纵向加密

## 3. 目标平台

- **操作系统**：openEuler（国产 Linux）
- **硬件**：RK3588
- **可靠性**：MTBF ≥ 50,000小时
