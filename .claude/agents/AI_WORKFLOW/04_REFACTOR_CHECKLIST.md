# 🔍 重构验证清单

每次重构或代码变更后，必须验证以下内容：

## 编译与测试验证

- [ ] `cargo build` 编译成功，无错误
- [ ] `cargo clippy` 无警告
- [ ] `cargo test` 所有测试通过
- [ ] `cargo fmt` 格式化检查通过

## 功能回归验证

根据变更模块选择验证：

### 通信网关
- [ ] 北向协议（IEC 104/IEC 61850/MQTT）连接建立正常
- [ ] 南向协议（RS485/HPLC/以太网）通信正常
- [ ] 协议转换数据一致性

### 数据处理引擎
- [ ] 遥测数据上送频率满足 ≥1Hz 要求
- [ ] 故障录波触发正常
- [ ] 数据聚合正确

### 本地策略引擎
- [ ] 削峰填谷策略生效
- [ ] 需量控制策略生效
- [ ] 防逆流策略生效

### AI 优化引擎
- [ ] LSTM/TCN 预测模型加载正常
- [ ] MADDPG/PPO 决策输出正常
- [ ] AI 失效时自动切换兜底机制

### 核间通信
- [ ] 共享内存读写正常
- [ ] `ai_ready` 信号正确
- [ ] `strategy_mode` 切换正常
- [ ] `control_cmd` 下发正常

### 设备管理
- [ ] 设备台账查询正常
- [ ] OTA 升级流程正常

## 安全验证

- [ ] 无硬编码密钥（检查代码中是否仍有 `SM2`/`SM4` 密钥残留）
- [ ] TLS 连接证书验证正常
- [ ] 国密算法调用正常

## 代码质量检查

- [ ] 无新增 `unwrap()` 调用（除非明确不会失败）
- [ ] 无新增 `unsafe` 块（除非确有必要且有注释说明）
- [ ] 错误类型实现了 `std::error::Error`
- [ ] 模块 public API 有文档注释
