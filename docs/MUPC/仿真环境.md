# Grid2Op + Pandapower 农网台区 MUPC 仿真环境构建指南

## 一、 使用 Pandapower 搭建农网台区物理拓扑

针对“高比例新能源+强冲击负荷”的低压农网台区，需从零构建包含变压器、长距离架空线、光伏、储能（MUPC）和冲击负荷的自定义网络。

### 1. 核心建模代码

```python
import pandapower as pp
import numpy as np

def create_agri_mupc_network():
    # 1. 创建空网络 (50Hz)
    net = pp.create_empty_network(name="Agri_MUPC_LV_Network", f_hz=50.0)
  
    # 2. 外部电网 (10kV高压侧)
    ext_bus = pp.create_bus(net, vn_kv=10.0, name="HV_Grid")
    pp.create_ext_grid(net, bus=ext_bus, vm_pu=1.0, va_degree=0)
  
    # 3. 配电变压器 (400kVA, 10/0.4kV)
    lv_bus = pp.create_bus(net, vn_kv=0.4, name="LV_Main_Bus")
    pp.create_transformer(net, hv_bus=ext_bus, lv_bus=lv_bus, 
                          std_type="0.4 MVA 10/0.4 kV", name="Dist_Transformer")
  
    # 4. 农网主干线路 (模拟长距离、高阻抗导致的电压跌落)
    # 使用典型农网架空线 LGJ-70/10，长度1.5km
    end_bus = pp.create_bus(net, vn_kv=0.4, name="End_Node_Bus")
    pp.create_line(net, from_bus=lv_bus, to_bus=end_bus, length_km=1.5, 
                   std_type="NAYY 4x50 SE", name="Main_Overhead_Line")
  
    # 5. 常规居民负荷 (晚上6-9点 40-50kW，9-11点 20kW)
    # 注意：这里 p_mw 初始值设为0，实际值由 Grid2Op Chronics 动态注入
    pp.create_load(net, bus=end_bus, p_mw=0.0, q_mvar=0.0, 
                   name="Residential_Load", controllable=False)
  
    # 6. 农业冲击负荷 (抽水灌溉/炒茶机，峰值300kW，强随机性)
    pp.create_load(net, bus=end_bus, p_mw=0.0, q_mvar=0.0, 
                   name="Agri_Shock_Load", controllable=False)
  
    # 7. 分布式光伏 (出力随机)
    pp.create_sgen(net, bus=end_bus, p_mw=0.0, q_mvar=0.0, 
                   name="Rooftop_PV", controllable=True)
  
    # 8. MUPC 储能装置 (可控充放电 + 无功支撑)
    pp.create_storage(net, bus=end_bus, p_mw=0.0, max_e_mwh=0.2, 
                      soc_percent=50.0, name="MUPC_BESS", controllable=True)
  
    return net
```

### 2. 专家关键提醒

* **三相不平衡问题**：上述代码为单相等效模型。若 MUPC 需解决三相电压不平衡，必须将 `create_load` 替换为 `create_asymmetric_load`，并使用 `pp.runpp_3ph(net)` 进行三相潮流计算，同时需在 Grid2Op 中编写自定义 Backend。
* **线路参数真实性**：农网末端电压问题的根源在于线路阻抗。务必根据实际导线型号（如 LGJ-70）修改 `std_type`，切勿使用默认电缆参数，否则仿真电压跌落将与现实严重不符。

## 二、 Grid2Op 与 MUPC AI 训练管线无缝对接

通过自定义三大核心组件，将 Pandapower 网络转化为 MUPC AI 训练环境。

### 1. 自定义时序数据注入 (Chronics)

Grid2Op 默认数据格式不适合农网，需编写自定义 `ChronicsHandler` 注入负荷/光伏曲线：

```python
class AgriChronics:
    def get_load_at(self, timestep):
        hour = timestep % 24
        season = get_current_season(timestep)
      
        # 居民负荷逻辑
        if 18 <= hour <= 21: 
            res_load = np.random.uniform(40, 50) / 1000
        elif 21 < hour <= 23: 
            res_load = 20 / 1000
        else: 
            res_load = 0.0
      
        # 农业冲击负荷逻辑 (季节性 + 随机性)
        agri_load = 0.0
        if season in ["irrigation", "tea_roasting"]:
            # 模拟多台机械启停的随机阶跃

        return {"Residential_Load": res_load, "Agri_Shock_Load": agri_load}
```

### 2. 自定义动作空间 (Action Space)

限制动作空间，仅暴露 MUPC 有功和无功控制接口：

```python
from grid2op.Action import BaseAction

class MUPCAction(BaseAction):
    def __init__(self, action_space):
        super().__init__(action_space)
        # 仅允许控制 storage (MUPC) 的有功和无功
        self.storage_p = [0.0]  # 对应 MUPC_BESS 的 p_mw
        self.storage_q = [0.0]  # 对应 MUPC_BESS 的 q_mvar
```

> **对接要点**：AI 训练管线中神经网络输出层应为 2 维连续向量 `[p_batt, q_batt]`，通过自定义 Action 类映射到 Grid2Op 的 `storage_p` 和 `storage_q`。

### 3. 自定义奖励函数 (Reward)

将 MUPC 多目标优化策略写入 Reward 类，引导 AI 学习：

```python
from grid2op.Reward import BaseReward

class MUPCReward(BaseReward):
    def __call__(self, action, env, has_error, is_done, is_illegal, is_ambiguous):
        if has_error or is_done: 
            return -100.0
      
        obs = env.observation
        reward = 0.0
      
        # 1. 电压质量奖励 (鼓励电压维持在 0.95-1.05 pu)
        v_dev = abs(obs.voltage_phase_a - 1.0)
        reward -= 10.0 * max(0, v_dev - 0.05) 
      
        # 2. 光伏消纳奖励 (减少弃光)
        reward += 1.0 * obs.pv_production_consumed
      
        # 3. 电池寿命惩罚 (抑制频繁大功率充放)
        reward -= 0.5 * abs(action.storage_p[0]) 
      
        return reward
```

### 4. 与现有 AI 管线对接清单


| AI 管线组件       | Grid2Op 对接方式                                         | 注意事项                           |
| :---------------- | :------------------------------------------------------- | :--------------------------------- |
| 状态输入 (State)  | 继承`BaseObservation`，提取`voltage`,`soc`,`pv`,`load`等 | 确保归一化到 [-1, 1] 或 [0, 1]     |
| 动作输出 (Action) | 自定义`MUPCAction`，映射`storage_p/q`                    | 添加动作合法性校验（如 SOC 边界）  |
| 奖励信号 (Reward) | 自定义`MUPCReward`                                       | 奖励尺度需调试，避免梯度爆炸       |
| 训练循环          | 直接使用`env.reset()`/`env.step()`                       | 完全兼容 Stable-Baselines3 / RLlib |
| 物理验证          | Grid2Op 内部自动调用 Pandapower                          | 无需手动调用`pp.runpp()`           |

## 三、 专家最终建议

1. **先跑通单相，再升级三相**：强烈建议先用单相等效模型跑通整个 RL 训练流程，验证奖励函数和动作空间设计合理性。确认收敛后再引入三相不平衡模型，避免一开始就陷入复杂调试泥潭。
2. **性能瓶颈预警**：Pandapower 每步耗时约 10-50ms，RL 训练百万步可能需要数十小时。**务必在训练阶段将 Backend 切换为 `lightsim2grid`**（C++ 加速后端），速度可提升 20-50 倍，且 API 完全兼容。
3. **安全约束硬编码**：农网设备耐受能力差。建议在 `MUPCAction` 中添加**硬性安全掩码（Safety Mask）**，当检测到电压越限或变压器过载时，强制覆盖 AI 输出，优先保障设备安全，再让 AI 学习恢复策略。
