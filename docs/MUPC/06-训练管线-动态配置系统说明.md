# MUPC 训练管线动态配置系统说明

> **适用对象**：MUPC AI 引擎（Rust/RK3588 NPU）开发团队
> **版本**：v1.0
> **关联训练管线**：MUPC-AI2 `config/` 系统
> **目的**：确保 AI 引擎侧物理参数与训练环境完全一致，消除 Sim-to-Real 偏差

---

## 1. 背景：为什么需要统一的配置系统

RL训练环境与部署环境之间的物理参数差异（Sim-to-Real Gap）会导致模型在训练阶段学到的策略在真实环境中失效。

**典型问题示例**：

| 训练侧（错误） | 部署侧（正确） | 影响 |
|---|---|---|
| 电池最大充放电功率 100 kW | 50 kW | 模型输出动作超出硬件承受范围 |
| 变压器容量 500 kVA | 200 kVA |策略忽视过载保护 |
| 光伏容量 150 kW | 150 kW（已对齐） | — |

为解决此问题，训练管线 v2.6 将所有物理参数统一外置到 YAML 配置文件中，训练与部署共享同一份配置来源。

---

## 2. 配置文件结构

配置文件路径：`config/mupc_env_config.yaml`

完整结构分为 10 个章节：

```yaml
# ═══════════════════════════════════════════════════════════════
# 物理常量 (SAFETY: 修改前请评审)
# ═══════════════════════════════════════════════════════════════
physical:
  transformer_kva: 200.0         # 变压器额定容量 (kVA)
  battery_capacity_kwh: 100.0 # 电池容量 (kWh)
  p_batt_max_kw: 50.0            # 最大充放电功率 (kW)
  q_batt_max_kvar: 300.0         # 最大无功输出 (kVar)
  load_shed_max_kw: 60.0         # 最大切负荷 (kW)
  pv_array_kw: 150.0 # 光伏容量 (kW)
  load_peak_kw: 60.0             # 负荷峰值 (kW)

# ═══════════════════════════════════════════════════════════════
# 安全约束 (SAFETY: 硬约束，不可突破)
# ═══════════════════════════════════════════════════════════════
safety:
  soc_min: 0.10                  # SOC 下限硬约束（10%）
  soc_max: 0.90                  # SOC 上限硬约束（90%）
  overload_threshold: 0.85       # 过载阈值（变压器额定容量85%）
  battery_charge_efficiency: 0.90  # 充电效率（锂离子电池典型值 90%）
  battery_discharge_efficiency: 0.90  # 放电效率（锂离子电池典型值 90%）

# ═══════════════════════════════════════════════════════════════
# 时间参数
# ═══════════════════════════════════════════════════════════════
time:
  dt_hours: 0.25                 # 时间步长（15分钟 = 0.25小时）
  episode_length: 96              # 每_episode步数（96 × 15分钟 = 24小时）
  load_pf: 0.90                  # 负荷功率因数 cosφ

# ═══════════════════════════════════════════════════════════════
# 合同与排放
# ═══════════════════════════════════════════════════════════════
contract:
  contract_demand_kw: 300.0 # 合同需量 (kW)
  grid_emission_factor: 0.581    # 电网排放因子 kg CO2/kWh

# ═══════════════════════════════════════════════════════════════
# 电压仿真 (VoltageSimulator 简化模型)
# ═══════════════════════════════════════════════════════════════
voltage_simulator:
  k_p: 0.05                      # 有功灵敏度系数 (p.u. / S_BASE)
  k_q: 0.03                      # 无功灵敏度系数 (p.u. / S_BASE)
  s_base: 500.0                  # 基准功率 (kVA)
  v_min: 0.85                    # 电压下限 (p.u.)
  v_max: 1.15                    # 电压上限 (p.u.)
  noise_std: 0.005               # 测量噪声标准差
  imbalance: 0.003               # 三相不平衡度
  impedance_drift_pct: 0.10       # 动态阻抗扰动 ±10%（v2.9 新增，模拟线路老化/温度变化）
  harmonic_3rd_pct: 0.03          # 3次谐波 3% 幅值（v2.9 新增，模拟农网谐波污染）
  harmonic_5th_pct: 0.02          # 5次谐波 2% 幅值（v2.9 新增）

# ═══════════════════════════════════════════════════════════════
# Q_batt 电压环控制参数
# ═══════════════════════════════════════════════════════════════
q_control:
  k_q: 200.0                     # 无功-电压灵敏度系数 (kVar/p.u.)

# ═══════════════════════════════════════════════════════════════
# 奖励阈值
# ═══════════════════════════════════════════════════════════════
reward_thresholds:
  voltage_deadband: 0.05         # ±5% 电压死区
  q_margin_threshold: 0.10     # 实时模块无功耗尽阈值（10%）
  voltage_high_limit: 1.05       # 弃光前置电压阈值 (p.u.)
  soc_critical: 0.10             # SOC 极低保护阈值
  voltage_penalty_high: 2.0      # 高电压惩罚系数
  voltage_penalty_low: 1.0      # 低电压惩罚系数

# ═══════════════════════════════════════════════════════════════
# 动作约束 (ActionValidator)
# ═══════════════════════════════════════════════════════════════
action_constraints:
  p_batt_max: 50.0               # kW（电池最大充放电功率）
  s_max: 200.0                   # kVA（功率圆上限，匹配变压器容量）
  load_shed_max: 60.0            # kW（最大切负荷）
  delta_p_max: 50.0              # kW/步（电池变化率保护）

# ═══════════════════════════════════════════════════════════════
# 动作空间定义（归一化空间，RL 输出范围）
# ═══════════════════════════════════════════════════════════════
action_space:
  p_batt_norm_min: -1.0          # → 物理值 [-50, 50] kW
  p_batt_norm_max: 1.0
  load_shed_norm_min: 0.0        # → [0, 60] kW
  load_shed_norm_max: 1.0
  pv_limit_min: 0.0              # 光伏限功率比例
  pv_limit_max: 1.0

# ═══════════════════════════════════════════════════════════════
# 通信延迟模拟（v2.9 新增，逼 AI 学到容忍 RTU 轮询延迟的策略）
# ═══════════════════════════════════════════════════════════════
comm:
  action_delay_steps_min: 1        # 最小延迟步数（1步=15分钟）
  action_delay_steps_max: 3        # 最大延迟步数（模拟 RTU 轮询周期 15~45min）

# ═══════════════════════════════════════════════════════════════
# 观测空间归一化参数
# ═══════════════════════════════════════════════════════════════
obs_normalization:
  d1_pv_range: [0.0, 150.0]      # D1 光伏归一化范围
  d1_load_range: [0.0, 60.0]     # D1 负荷归一化范围
  d1_power_range: [-500.0, 500.0]
  d1_voltage_range: [0.85, 1.15]
  d5_irradiance_range: [0.0, 1500.0]
  d5_temp_range: [-20.0, 60.0]
  d6_dispatch_range: [-500.0, 500.0]

# ═══════════════════════════════════════════════════════════════
# 场景奖励权重
# ═══════════════════════════════════════════════════════════════
reward_weights:
  MODE-01: [1.0, 0.5, 2.0, 1.0, 0.5]   # w1~w5
  MODE-02: [1.0, 1.0, 2.0]
  MODE-03: [1.0, 0.5]
  MODE-04: [1.0, 2.0, 1.0]
  MODE-05: [1.0, 1.0]
```

## 3. AI 引擎侧必须对齐的关键参数

以下参数为 **硬件规格**，AI 引擎侧必须使用完全相同的数值，否则模型行为将与训练时产生偏差：

### 3.1 物理常量（`physical`）

| 参数 | 值 | 说明 |
|---|---|---|
| `transformer_kva` | **200 kVA** | 变压器额定容量，用于过载判断 |
| `battery_capacity_kwh` | **100 kWh** | 电池总容量，用于 SOC 计算 |
| `p_batt_max_kw` | **50 kW** | 电池最大充放电功率（RL 动作空间上限） |
| `q_batt_max_kvar` | **300 kVar** | 电池最大无功输出 |
| `load_shed_max_kw` | **60 kW** | 可切负荷上限（RL 动作空间上限） |
| `pv_array_kw` | **150 kW** | 光伏装机容量 |
| `load_peak_kw` | **60 kW** | 负荷峰值 |

### 3.2 安全约束（`safety`）

| 参数 | 值 | 说明 |
|---|---|---|
| `soc_min` | **0.10（10%）** | SOC 硬下限，不可突破 |
| `soc_max` | **0.90（90%）** | SOC 硬上限，不可突破 |
| `overload_threshold` | **0.85（85%）** | 变压器过载判断阈值 |
| `battery_charge_efficiency` | **0.90** | 充电效率（锂离子电池典型值 90%） |
| `battery_discharge_efficiency` | **0.90** | 放电效率（锂离子电池典型值 90%） |

### 3.3 动作空间（`action_space` / `action_constraints`）

RL 模型输出 3 维动作向量，**归一化到 [-1, 1]**（p_batt）和 [0, 1]（load_shedding, pv_limit）。AI 引擎部署时需将归一化输出反归一化到物理值：

```
p_batt_physical = p_batt_norm × 50 kW       （范围 [-50, 50] kW）
load_shedding_physical = load_shed_norm × 60 kW   （范围 [0, 60] kW）
pv_limit_physical = pv_limit_norm （范围 [0, 1]，无量纲）
```

**动作约束（ActionValidator）反归一化关系**：

| 归一化输出 | 反归一化物理值 | 来源 |
|---|---|---|
| A1 ∈ [-1, 1] | p_batt ∈ [-50, 50] kW | `p_batt_max` |
| A2 ∈ [0, 1] | load_shedding ∈ [0, 60] kW | `load_shed_max` |
| A3 ∈ [0, 1] | pv_limit ∈ [0, 1] | 无量纲 |

## 4. SOC 计算公式

AI 引擎侧 SOC 计算必须使用以下公式，与训练环境一致：

```
ΔSOC = p_batt × dt_hours / battery_capacity_kwh
SOC_next = clip(SOC_current + ΔSOC, soc_min, soc_max)
```

其中 `dt_hours = 0.25`（15分钟），`battery_capacity_kwh = 100`。

## 5. 训练时如何使用配置

### 5.1 启动训练时加载配置

```bash
python train.py --config config/mupc_env_config.yaml --mode MODE-01 --total-timesteps 50000
```

`--config` 参数可选。不指定时，训练管线使用代码中的硬编码默认值（向后兼容）。

### 5.2 代码中读取配置

```python
from config import get_config, load_config

# 加载配置（通常在 train.py 入口调用一次）
load_config("config/mupc_env_config.yaml")

# 之后在任意模块获取配置
cfg = get_config()
print(cfg.physical.p_batt_max_kw)   # 50.0
print(cfg.safety.soc_min)            # 0.10
```

所有模块（`mupc_env.py`、`data_loader.py`、`action_validator.py` 等）均通过 `get_config()` 获取参数，不再持有硬编码常量。

## 6. 部署核对清单（AI 引擎侧）

在 AI 引擎（Rust/RK3588 NPU）部署模型前，请核对以下参数与训练配置完全一致：

###硬件规格
- [ ] 变压器容量 = **200 kVA**（`physical.transformer_kva`）
- [ ] 电池最大充放电功率 = **50 kW**（`physical.p_batt_max_kw`）
- [ ] 电池总容量 = **100 kWh**（`physical.battery_capacity_kwh`）
- [ ] 光伏容量 = **150 kW**（`physical.pv_array_kw`）
- [ ] 最大切负荷 = **60 kW**（`physical.load_shed_max_kw`）
- [ ] 最大无功输出 = **300 kVar**（`physical.q_batt_max_kvar`）

### 安全约束
- [ ] SOC 下限 = **10%**（`safety.soc_min`），低于此值强制停机
- [ ] SOC 上限 = **90%**（`safety.soc_max`），高于此值停止充电
- [ ] 过载阈值 = **85%**（`safety.overload_threshold`）

### 动作反归一化
- [ ] ONNX 输出 shape = **(1, 3)**，第 1维为 batch
- [ ] A1 反归一化：`p_batt = A1[0] × 50 kW`
- [ ] A2 反归一化：`load_shedding = A2[0] × 60 kW`
- [ ] A3 原值输出：`pv_limit = A3[0]`（无量纲，范围 [0, 1]）

### 状态转移
- [ ] 时间步长 = **0.25 小时**（15分钟）
- [ ] SOC 递推：`SOC_new = clip(SOC + p_batt × 0.25 / 100, 0.10, 0.90)`
