## 2. 模块设计：LSTM 模型增强

### 2.1 Attention 机制

**文件**：`lstm_model.py`

**新增类 `AdditiveAttention`**（ONNX 可导出的标准算子组合）：

```python
class AdditiveAttention(nn.Module):
    """加法注意力 (Bahdanau), 所有算子 ONNX 标准.
    
    Input:  (batch, seq_len, hidden_dim)  LSTM hidden states
    Output: (batch, hidden_dim)           上下文向量
    Optional: attention_weights (batch, seq_len)  可视化输出
    """
    def __init__(self, hidden_dim: int):
        self.W = nn.Linear(hidden_dim, hidden_dim)   # 线性变换
        self.v = nn.Linear(hidden_dim, 1)             # 评分标量

    def forward(self, h: Tensor) -> tuple[Tensor, Tensor]:
        score = self.v(torch.tanh(self.W(h)))     # (B, T, 1)
        weights = torch.softmax(score, dim=1)     # (B, T, 1)
        context = torch.sum(weights * h, dim=1)   # (B, H)
        return context, weights.squeeze(-1)
```

**关键算子验证**（全部 ONNX 标准）：
| 算子 | ONNX op | RKNN 支持 |
|------|---------|-----------|
| Linear (MatMul + Add) | `Gemm` | ✅ |
| Tanh | `Tanh` | ✅ |
| Softmax | `Softmax` | ✅ |
| ReduceSum (with broadcasting) | `ReduceSum` + `Mul` | ✅ |

### 2.2 LSTM 模型结构变更

`LSTMForecast.__init__` 新增参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `with_attention` | `bool` | `True` | 是否含 Attention 层 |
| `attn_score` | `str` | `"additive"` | 注意力评分类型（当前仅 additive，预留 multiplicative/dot） |
| `input_window` | `int` | `12` | 输入窗口步数（12/24/36，由 MSSA 确定） |
| `output_mode` | `str` | `"p10p50p90"` | 输出模式（"p10p50p90" 3 通道 或 "legacy" 双头 30 维） |

### 2.3 Forward 计算图变更

```
改造前:                                     改造后 (R1):
x (B, T, 7)                                x (B, T, K)   K ≤ 7, 由 MIC 筛选
  → LSTM → h (B, T, H)                       → LSTM → h (B, T, H)   H=hidden_dim
  → h[:,-1,:] (取最后一步)                    → AdditiveAttention(h) → ctx (B, H)
  → head_pv (15) / head_load (15)            → head_pv (B, T, 15) reshape → (B, 15)
                                             → head_load (B, T, 15)
                                             → stack → (B, 2, 15)

改造后 (R1 含分位数):
x (B, T, K)
  → LSTM → h (B, T, H)
  → AdditiveAttention(h) → ctx (B, H)
  → FC_out (B, 2, 15, 3)   # 2个目标 × 15步 × (P10, P50, P90)
```

**输出维度对照**：

| 场景 | 输出 shape | 对应改造要求 |
|------|-----------|-------------|
| 无 VMD, R1 | `(B, 2, 15, 3)` PV/Load × 15步 × (P10,P50,P90) | §1.4.1 |
| 含 VMD, R2 | `(B, K, 2, 15, 3)` K=模态数 | §1.4.2 |
| 向后兼容 (legacy) | `(B, 47)` 旧 47 维 | 过渡期 |

### 4.3 分步 MAPE 计算

```python
def compute_mape(pred: np.ndarray, true: np.ndarray, step: int = 1) -> float:
    """计算指定步数的 MAPE.
    
    Args:
        step: 1 表示第 1 步, 15 表示第 15 步
    """
    p = pred[:, step - 1]    # (N,)
    t = true[:, step - 1]    # (N,)
    mask = t > 1e-3
    return float(np.mean(np.abs((p[mask] - t[mask]) / t[mask])))
```

### 4.4 错误处理

```python
try:

    sys.exit(1)  # 非零退出码, MSSA 标记为无效
```

## 5. 模块设计：数据交换接口

### 5.1 MIC JSON 读取

**文件**：`data_loader.py` 新增函数

```python
def load_mic_features(json_path: str) -> tuple[list[str], int]:
    """读取 MIC 分析结果, 返回 (selected_features, top_k).
    
    Args:
        json_path: MIC 离线分析输出的 JSON 文件路径
    Returns:
        (selected_feature_names, top_k)
    """
    with open(json_path) as f:
        mic = json.load(f)
    selected = [feat["name"] for feat in mic["features"] if feat["selected"]]
    top_k = mic["top_k"]
    if len(selected) != top_k:
        logging.warning(f"MIC selected {len(selected)} features != top_k {top_k}, "
                        f"using actual selection count")
    return selected, top_k
```

### 5.2 MSSA JSON 读取

```python
def load_mssa_result(json_path: str) -> dict:
    """读取 MSSA 搜索结果, 返回最优超参.
    
    Returns:
        {"hidden_size": 64, "num_layers": 2, ...}
    """
    with open(json_path) as f:
        mssa = json.load(f)
    if mssa.get("quality_flag") == "unusable":
        logging.warning("MSSA quality_flag=unusable, consider using manual baseline")
        return DEFAULT_HYPERPARAMS  # fallback 到人工基线
    return mssa["best_hyperparameters"]
```

### 5.3 训练数据指纹

```python
def compute_data_fingerprint(data_dir: str) -> str:
    """计算训练数据指纹 (CSV 文件 SHA256 前 16 位)."""
    import hashlib
    hasher = hashlib.sha256()
    for csv_path in sorted(Path(data_dir).rglob("*.csv")):
        hasher.update(csv_path.read_bytes())
    return hasher.hexdigest()[:16]
```

### 6.3 真分位数回归 (非本轮, 预留接口)

```python
class QuantileLoss(nn.Module):
    """Pinball Loss (分位数损失), 预留接口.
    
    用法: 将 LSTMTrainer 的 loss_fn 从 Huber → QuantileLoss(p=[0.1, 0.5, 0.9])
    """
    def __init__(self, quantiles: list[float] = [0.1, 0.5, 0.9]):
        self.quantiles = quantiles

    def forward(self, pred: Tensor, target: Tensor) -> Tensor:
        # pred: (B, 2, 15, 3), target: (B, 2, 15, 3)
        losses = []
        for i, q in enumerate(self.quantiles):
            error = target[..., i] - pred[..., i]
            losses.append(torch.max(q * error, (q - 1) * error))
        return torch.mean(torch.stack(losses))
```

## 7. 模块设计：误差修正 BiLSTM

### 7.1 架构

**新增文件**：`error_correction.py`

```python
class ErrorCorrectionBiLSTM(nn.Module):
    """独立轻量 BiLSTM, 用于残差修正 (R2).
    
    Input:  (B, residual_window, 1)  历史残差序列
    Output: (B, 15, 1)               未来残差预测
    """
    def __init__(self, hidden_dim: int = 32, num_layers: int = 1,
                 residual_window: int = 24):
        self.bilstm = nn.LSTM(1, hidden_dim, num_layers,
                              bidirectional=True, batch_first=True)
        self.head = nn.Linear(hidden_dim * 2, 1)

    def forward(self, x: Tensor) -> Tensor:
        h, _ = self.bilstm(x)        # (B, T, 2H)
        return self.head(h[:, -15:])  # (B, 15, 1)
```

### 7.2 训练流程

```python
class ErrorCorrectionTrainer:
    def train(self, data: dict, main_model: LSTMForecast) -> dict:
        """训练误差修正模型.
        
        步骤:
        1. 用主模型对训练集做预测
        2. 计算残差序列 e = y_true - y_pred (仅 P50)
        3. 以历史残差为输入 (窗口=24)、未来残差为输出 (15步)
        4. 训练独立轻量 BiLSTM
        5. 偏差检查: main_model Bias > 3% MAPE 时启用; 否则跳过
        """
        # Step 1-2: 预测与残差
        main_pred = main_model.predict_numpy(X)
        residuals = y_true[..., 1] - main_pred[..., 1]  # P50 channel

        # Step 3: 构造残差训练数据
        X_err, y_err = self._prepare_residual_data(residuals)

        # Step 4: 训练
        ...
        # Step 5: 偏差检查
        bias = np.mean(residuals)
        if abs(bias) < 0.03 * np.mean(np.abs(y_true[..., 1])):
            logging.info("Bias < 3%, skip error correction training")
            return {"skip": True}

        return {"skip": False, "bias": float(bias), "history": history}
```
