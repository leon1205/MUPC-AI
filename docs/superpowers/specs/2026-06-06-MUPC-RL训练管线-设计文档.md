### 1.3 R1 vs R2 分轮交付策略

| 轮次 | 交付物 | 必须 |
|------|--------|------|

### 3.3 物理仿真方程

```python
def _physics_step(self, action_clamped):
    # 1. 动作反归一化 (v2.15: 2 维 [p_ref, k_droop])
    p_ref   = action_clamped[0] * 50.0       # [-50, 50] kW
    k_droop = action_clamped[1] * 100.0      # [-100, 100] kW/V
    q_batt  = self._q_batt_realtime          # Q 由实时电压调节器闭环 (不经过 RL)
    load_shedding = 0.0; pv_limit = 1.0      # 下沉至 strategy-engine

    # 2. 有效负荷和光伏
    p_load_eff = max(0, p_load_raw - load_shedding)
    p_pv_eff = p_pv_raw * pv_limit

    # 3. SOC 更新 (SAFETY: hard clamp [10%, 90%])
    soc_raw = self.soc + (-p_ref * 0.25) / 100.0
    soc_new = np.clip(soc_raw, 0.10, 0.90)

    # 4. 电网交换功率 + 变压器负载率
    grid_power = p_load_eff - p_pv_eff + p_ref
    q_load = p_load_eff * tan(acos(0.90))
    s_trafo = sqrt(grid_power**2 + (q_load - q_batt)**2)
    load_rate = s_trafo / 200.0

    # 5. 电压更新 (Grid2Op 或 VoltageSimulator)
    if self._use_grid2op:
        va, vb, vc = self._grid2op_step(p_ref, q_batt, k_droop)
    else:
        p_net = p_pv_eff - p_load_eff + p_ref
        va, vb, vc = self.voltage_sim.step(p_net, q_batt, ...)

    # 6. 下垂控制公式 (v3.1 对齐下游):
    #    P_output = P_ref - k_droop × ΔV
    #    电压偏高 (ΔV>0): P_output↓ → 趋向充电 → 拉低电压 ✓
    #    电压偏低 (ΔV<0): P_output↑ → 趋向放电 → 抬升电压 ✓
```

### 3.4 q_realtime_margin 的训练模拟


## 6. LSTM 预测模型 (v3.0 预测增强核心)

> **v3.0 变更**：LSTM 从简单的"取最后步 hidden + 2 头 Linear"升级为 **LSTM + AdditiveAttention + 6 头分位数输出**。输入窗口从 8 步扩展到 12/24/36 步 (MSSA 搜索)，特征维度从固定 7 维变为 MIC 筛选 K 维。支持双向 LSTM (BiLSTM) 可选增强。

### 6.1 AdditiveAttention 注意力机制

**文件**：`lstm_model.py`

**新增类 `AdditiveAttention`**（全部 ONNX 标准算子）：

```python
class AdditiveAttention(nn.Module):
    """加法注意力 (Bahdanau), 所有算子 ONNX 标准.
    Input:  (B, seq_len, H)  LSTM hidden states
    Output: (B, H)           上下文向量
    """
    def __init__(self, hidden_dim: int):
        self.W = nn.Linear(hidden_dim, hidden_dim)  # Gemm
        self.v = nn.Linear(hidden_dim, 1)           # Gemm

    def forward(self, h: Tensor) -> tuple[Tensor, Tensor]:
        score = self.v(torch.tanh(self.W(h)))   # (B, T, 1): Tanh
        weights = torch.softmax(score, dim=1)   # (B, T, 1): Softmax
        context = torch.sum(weights * h, dim=1) # (B, H):   Mul + ReduceSum
        return context, weights.squeeze(-1)
```

**ONNX 算子验证**（全部 RKNN 支持）：
| 算子 | ONNX op | RKNN |
|------|---------|------|
| Linear | Gemm | ✅ |
| Tanh | Tanh | ✅ |
| Softmax | Softmax | ✅ |
| Mul + ReduceSum | Mul + ReduceSum | ✅ |

**设计决策**：选择 AdditiveAttention 而非 Self-Attention，因为 (1) 24 步短序列下加法注意力足够；(2) 参数量 ~H² 远小于 Self-Attention 的 3H²；(3) 全算子 ONNX 标准，NPU 可直接推理。

### 6.2 p10p50p90 分位数输出格式

**LSTMForecast 新参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `input_dim` | int | 7 | MIC 筛选后的特征维度 |
| `hidden_dim` | int | 64 | LSTM 隐状态维度 (MSSA 搜索) |
| `num_layers` | int | 2 | LSTM 层数 |
| `input_window` | int | 12 | 输入窗口步数 (12/24/36, MSSA 搜索) |
| `output_mode` | str | "p10p50p90" | "p10p50p90" 三通道 或 "legacy" 双头 |
| `with_attention` | bool | True | 是否含 Attention |
| `attn_score` | str | "additive" | 注意力评分类型 |
| `bidirectional` | bool | False | 是否双向 LSTM (R2) |

**forward 计算图**：

```
x (B, T, K)   K ≤ 7, T ∈ {12, 24, 36}
  → LSTM → h_seq (B, T, H)
  → AdditiveAttention(h_seq) → ctx (B, H)
  → 6 个 Linear 头:
      head_pv_p10/head_pv_p50/head_pv_p90 → 各 (B, 15)
      head_load_p10/head_load_p50/head_load_p90 → 各 (B, 15)
  → stack → (B, 2, 15, 3)   # PV/Load × 15步 × (P10, P50, P90)
```

**输出维度对照**：

| 场景 | 输出 shape | 说明 |
|------|-----------|------|
| p10p50p90 (R1) | `(B, 2, 15, 3)` | PV/Load × 15步 × 三通道 |
| 含 VMD (R2) | `(B, K, 2, 15, 3)` | K=模态数 |
| legacy 兼容 | `(B, 47)` | 旧 47 维，过渡期 |

**p10p50p90 → legacy 转换** (`_p10p50p90_to_legacy()`): 提取 P50 通道 → (B, 30) D2 预测 + P90 通道 → (B, 17) D10 预测。

### 6.3 BiLSTM 双向增强（可选 R2, Go/No-Go 准入）

将单向 LSTM 替换为 BiLSTM，前向+后向隐状态拼接后送入 Attention：

```
正向 LSTM: t-T → ... → t      ─┐
反向 LSTM: t → ... → t-T      ─┤→ 拼接 [h_fwd; h_bwd] → Attention
```

**准入条件 (Go/No-Go Gate)**：

| 条件 | 结果 |
|------|------|
| RK3588 实测 ≥1000 次, P99 < 900ms | Go — BiLSTM 可启用 |
| P99 ≥ 900ms | No-Go — 降级至单向 LSTM |

BiLSTM 启用时 hidden_dim 折半以控制参数量 ≤ 单向的 2.2 倍。

## 7. 误差修正 BiLSTM (v3.0 R2)

**新增文件**：`error_correction.py`

### 7.1 架构

```python
class ErrorCorrectionBiLSTM(nn.Module):
    """独立轻量 BiLSTM, 用于残差修正。
    Input:  (B, 24, 1)  历史残差序列
    Output: (B, 15, 1)  未来残差预测
    """
    def __init__(self, hidden_dim=32, num_layers=1, residual_window=24):
        self.bilstm = nn.LSTM(1, hidden_dim, num_layers,
                              bidirectional=True, batch_first=True)
        self.head = nn.Linear(hidden_dim * 2, 1)

    def forward(self, x):
        h, _ = self.bilstm(x)        # (B, 24, 2H)
        return self.head(h[:, -15:]) # (B, 15, 1)
```

| 属性 | 规格 |
|------|------|
| 输入 | 最近 24 步历史残差 (冷启动时零向量) |
| 输出 | 未来 15 步预测残差 |
| hidden_dim | 32 |
| num_layers | 1 |
| 参数量 | ≤ 主 LSTM 的 50% |
| INT8 模型 | ≤ 3MB |

### 7.2 训练流程

```python
class ErrorCorrectionTrainer:
    def train(self, data, main_model: LSTMForecast) -> dict:
        """5 步训练:
        1. 主模型对训练集做预测 → y_pred_1
        2. 计算残差 e = y_true - y_pred_1 (P50 通道)
        3. 构建残差训练数据: X_err(24步历史残差) → y_err(15步未来残差)
        4. 训练轻量 BiLSTM (MSE loss)
        5. 偏差检查: |bias| < 3% MAPE → 跳过, 不导出模型
        """
```

**启用条件 (Bias Gate)**：`|bias| > 3% MAPE` 才启用误差修正，否则跳过训练且推理端不加载模型。

**推理阶段故障处理**：连续 3 次失败 → 自动禁用；连续 5 次成功 → 自动恢复。

## 9. 动作约束校验

**文件**：`action_validator.py`

**v3.1 版本**：2 维动作 `[p_ref, k_droop]`，5 条约束 ACT-01~05：

```python
class ActionValidator:
    P_BATT_MAX: float = 50.0              # kW
    K_DROOP_MIN: float = -100.0           # kW/V
    K_DROOP_MAX: float = 100.0            # kW/V
    DELTA_P_MAX: float = 50.0             # kW/步, ACT-01
    DELTA_K_DROOP_MAX: float = 10.0       # kW/V/步, ACT-02
    MAX_APPARENT_POWER_KVA: float = 200.0  # kVA, ACT-03 S-circle

    def validate(self, action_norm, dispatch_p=None):
        p_ref, k_droop = self._denormalize(action_norm)

        # ACT-01: |Δp_ref| ≤ 50 kW/步
        # ACT-02: |Δk_droop| ≤ 10 kW/V/步
        # ACT-03: √(p_ref² + k_droop²) ≤ 200 kVA (S-circle)
        # ACT-04: k_droop ∈ [-100, 100] kW/V
        # ACT-05: |p_ref| ≤ |dispatch_p| (调度权限)

        # 反归一化:
        #   p_ref   = a[0] × 50.0        → [-50, 50] kW
        #   k_droop = a[1] × 100.0       → [-100, 100] kW/V
```

**约束规则汇总**：

| 规则 | 约束条件 | 越限处理 |
|------|----------|----------|
| ACT-01 | \|Δp_ref\| ≤ 50 kW/步 | clamp |
| ACT-02 | \|Δk_droop\| ≤ 10 kW/V/步 | clamp |
| ACT-03 | √(p_ref² + k_droop²) ≤ 200 kVA | 等比缩放 |
| ACT-04 | k_droop ∈ [-100, 100] kW/V | clamp |
| ACT-05 | \|p_ref\| ≤ \|dispatch_p\| | clamp |

合成部署端由实时数据源提供的字段（电压/需量/调度），因 SMART-DS 仅含光伏/负荷/气象。

### TD-02：观测维度变更
v2.5 58/59 → v2.12 58/59 → v2.14 61/62 → v2.16 63/64 → v2.17 78/79 → v3.0 78/79 (不变，LSTM 内部升级为 p10p50p90)。

### TD-03：LSTM 训练在管线内
SMART-DS 数据可用于训练 LSTM，管线需要预测值作为 RL 状态输入。

### TD-04：训练步长保持 15 分钟
15 分钟粒度下 RL 已可学到有效策略。动作约束规则按 Δ/步 理解。

### TD-05：电压仿真技术选型
Grid2Op + Pandapower 三相潮流为主，VoltageSimulator 为降级方案。

### TD-06：分层控制架构
Q 控制交由实时控制核心根据电压闭环调节，RL 仅输出 P 控制指令。

### TD-07：AdditiveAttention 选型 (v3.0)
选择加法注意力而非自注意力：24 步短序列足够、参数量小 (H² vs 3H²)、全算子 ONNX 标准 NPU 直接推理。

### TD-08：三个模型独立部署 (v3.0)
lstm_attn (主力) + bilstm_attn (精英替补, Go/No-Go) + error_correction (校对员, Bias Gate)。独立 RknnRuntime、独立 OTA、独立降级。

### TD-09：MSSA 离线超参优化 (v3.0)
麻雀搜索算法替代人工 grid search。离线 Python 工具，不进入 RK3588 部署路径。
