### T3. 下垂公式文档表述对齐：本地 `-` 号 vs 下游 `+` 号

**问题**：本地 `grid2op_env/power_flow.py` 实际实现是 `P_output = P_ref - k_droop × ΔV`（物理正确），但本地文档/注释写的是 `P_output = P_ref + k_droop × ΔV`（与下游 PRD 文档表述一致但符号相反）。

**实际物理含义**：
- 本地代码：低电压时 ΔV < 0, 减负得正, 增发功率抬升电压 ✓
- 下游 PRD：`P = P_ref + k_droop × ΔV`，ΔV 定义取决于符号约定

**✅ 2026-06-17 已完成**: 本地代码 docstring + 注释统一为 `P_output = P_ref - k_droop × ΔV`, `mupc_env/core.py` + `grid2op_env/power_flow.py` 注释同步.

**影响**：仅文档表述差异，不影响实际推理（Rust 端独立实现）。
